## What it computes

Params `symbol`, `horizon_sessions` (default 250, clamped 250–500). Windows are
fixed in code so the numbers are not a function of the parameter the model
passed: 52-week band and 12-month return over the last **250 sessions**, zone
over the last **60**, RSI(14) over the last **100** (≈7× the period, past
Wilder's seed decay).

- price position: last close, 52w high/low from the `high`/`low` columns,
  percentile inside the band, drawdown from the high;
- accumulation zone: 20-bin histogram of the last 60 closes, the top **adjacent
  pair** of bins, ties to the lower pair (the only tie-break that is not a fact
  about iteration order). Labelled "vùng giá đóng cửa tập trung", no
  support/resistance semantics anywhere;
- momentum computed here, no Signal Field read (spec §2);
- earnings: 8 quarters, YoY on the 4 newest, `unknown` when fewer than 8
  comparable quarters exist;
- 6 conditions, labels fixed as module constants, statuses `met|not_met|unknown`
  by comparison, each naming the frame that holds its number.

Frames: `tiles`, `range_band`, `price_context`, `earnings_quarters`,
`conditions` → `stat_tiles`, `range_strip`, `line_series`, `bar_series`,
`condition_checklist`. Headline: `{symbol, asOfSession, sessionsUsed,
pricePosition, earningsTrend, latestQuarter, conditions{met,notMet,unknown,
items}}` — 922 chars on real STB data, ≈300 tokens.

## Where I followed the data, not the spec

1. **`conditions.items` is in the headline, not only the three counts.** The
   spec's headline was counts only, and the phase also requires the model to
   *narrate condition statuses*. Counts alone force it to invent the sentences.
   The items carry `{label, status}` — the labels are code constants, so nothing
   model-authored enters them, and no frame cell does either. Counts are still
   there, so the spec's shape is intact.
2. **No Universe gate.** The spec frees this Study from `get_field`'s
   declared-only rule, and item 3 requires a non-declared symbol to answer with
   `earnings unknown`. So membership is not checked at all: a symbol the daily
   backfill has not reached refuses with `insufficient_sessions`, which names
   the store rather than the company. Verified live: `A32` (494 daily sessions,
   1 quarter) answers with `earningsTrend: unknown` and `health: degraded`.
3. **A 52-week review needs 52 weeks.** `MIN_SESSIONS = 250`, and
   `horizon_sessions` cannot be clamped below it. Every fixed condition label
   says "52 tuần"; a window of 200 sessions labelled that way is a wrong number
   that looks right. The clamp floor is therefore the band, not a smaller value.
4. **`yoy_pct` requires a positive base quarter.** Measured: STB's Q4/2025 is
   −2.752e12. A percentage change *from* a loss is unusable ("−100 → +50" reads
   as "+150%"), so the frame's percentage is absent there while the trend
   classification uses the sign of the change, which is defined for any signs.
5. **Mixed `price_basis` in a window refuses** (`SignalIssue.MIXED_PRICE_BASIS`).
   Every stored row today is `adjusted_at_source`, so it is a guard rather than
   a branch anybody has seen — but the band, the return and the drawdown are
   exactly what a mixed window breaks silently.
6. **RSI answers `None` for a window that never moved**, not 50. Fifty is the
   midpoint of a *relative strength* scale, and a flat series has none to
   report; the condition then reads `unknown`.
7. **The wire-schema hash lock moved.** `run_study`'s parameters and description
   carry the Study catalog, so registering a Study changes the shipped tool
   bytes by design (`agent/tools/studies.py` says so explicitly, and phase 06
   moved the same literal). Updated with a comment saying what moves it —
   not silenced, not weakened.

## Acceptance

1. **Golden test** — `condition_fixture.py` plants a 250-session window
   (plateau 80.000 → decline → ramp 68.000–74.000 → 60-session cluster) and 8
   quarters. Every asserted figure is hand-derivable from the construction:
   band 67.900–80.100, percentile 28,28%, off-high −10,92%, 12m return −10,81%,
   zone 71.000–71.600 holding 33 of 60 sessions, latest YoY +38,46%, statuses
   5 met / 1 not met / 0 unknown. RSI has no closed form, so the *implementation*
   is pinned arithmetically (alternating ±1 seed → exactly 50; one more up
   change → exactly 100 × 7,5/14) and the fixture's value (51,19) is asserted
   against that proven function.
