# AI capability roadmap

The canonical capability roadmap has moved to the
[Harness roadmap](../harness-roadmap.md). The roadmap was separated from the
[System roadmap](../system-roadmap.md) so AI capability graduation and data
platform delivery no longer share one phase sequence.

The Harness roadmap preserves the architecture synthesized from Hermes and
OpenCode and applies it as a conformance gate to every phase. The binding
architecture decisions remain in
[Target architecture](target-architecture.md#adopt-adapt-and-reject).

This file remains as a compatibility pointer for historical plans and links. Do
not record phase status here.
